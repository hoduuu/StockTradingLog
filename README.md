# 미국주식 매매장부

얼마 넣었고, 뭘 몇 주 얼마에 사서, 얼마에 팔아 실제로 얼마 벌었는지 기록하는 개인용 매매 장부.

- 주계좌 / 부계좌 구분, 계좌별·종목별·전체 실현손익
- 입출금·매수·매도로 현금 자동 추적
- 종목별 스윙 매매를 사이클 단위로 묶어서 표시
- 투자 일기 (종목·거래 연결)
- 현재가·평가손익·API 없음 — 확정된 손익만 다룸

## 사용

`index.html`을 브라우저로 열면 됩니다. 서버·로그인·인터넷 불필요.
데이터는 브라우저 IndexedDB에 저장되며, **데이터** 탭에서 JSON 내보내기/가져오기/초기화를 할 수 있습니다.

실현손익은 이동평균법(매도금액 − 평균매수가 × 매도수량 − 수수료)으로 계산합니다.
